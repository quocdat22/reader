## 1. Goal & Preconditions

**Goal**: Install and configure the **pnpm + Vite + TypeScript + Svelte 5 + Vitest + ESLint + Prettier** toolchain at the repository root and connect `src-tauri/tauri.conf.json` to Vite (`devUrl` + `frontendDist: "../dist"`) so the **existing vanilla frontend builds and runs identically through Vite** with zero functional regressions.

**Preconditions**:
- Node.js (LTS or newer) and `pnpm` are installed on the machine.
- `src-tauri/resources/pdfium.dll` is present (run `.\scripts\fetch-pdfium.ps1` if needed).
- Existing Rust quality gates pass (`cargo fmt --check`, `cargo clippy --all-targets --all-features --locked -- -D warnings`, `cargo test` inside `src-tauri/`).

- Do not modify legacy `src/*.js` or `src/styles.css` behavior.
- Do not modify `AGENTS.md`, `docs/SPEC.md`, or `docs/PHASES.md` yet (deferred to Phase 5).

## 4. Detailed Technical Tasks

### 4.1 Initialize `package.json` and Install Dependencies
- Set `"private": true` and `"type": "module"`.
- Runtime dependencies (`dependencies`):
  - `@tauri-apps/api` (v2 matching `src-tauri/Cargo.toml`'s `tauri = "2"`)
  - `@tauri-apps/plugin-dialog` (v2 matching `tauri-plugin-dialog = "2"`)
- Development dependencies (`devDependencies`):
  - `svelte` (`^5`), `vite`, `@sveltejs/vite-plugin-svelte`
  - `typescript`, `svelte-check`, `tslib`
  - `vitest`
  - `eslint`, `@eslint/js`, `globals`, `typescript-eslint`, `eslint-plugin-svelte`, `eslint-config-prettier`
  - `prettier`, `prettier-plugin-svelte`
- Define scripts matching [ARCHITECTURE.md §6](../ARCHITECTURE.md#6-testing-linting--quality-gates):
  - `dev`, `build`, `preview`, `check`, `typecheck`, `lint`, `format`, `format:check`, `test`, `test:watch`, `verify`.

### 4.2 Configure Vite, Svelte, TypeScript & Vitest
1. **`vite.config.ts`**:
   - Register `svelte()` from `@sveltejs/vite-plugin-svelte`.
   - Set `clearScreen: false` so Rust/Tauri compiler output stays visible alongside Vite logs.
   - Set `server: { port: 1420, strictPort: true, watch: { ignored: ["**/src-tauri/**"] } }`.
   - Set `build: { target: "es2022", outDir: "dist", emptyOutDir: true }`.
2. **`svelte.config.js`**:
   - Export `{ preprocess: vitePreprocess() }`.
3. **`tsconfig.json`**:
   - Enable `"strict": true`, `"noUncheckedIndexedAccess": true`, `"noFallthroughCasesInSwitch": true`, `"moduleResolution": "bundler"`, `"target": "ES2022"`, `"module": "ESNext"`, `"isolatedModules": true`, `"verbatimModuleSyntax": true`, `"noEmit": true`, `"skipLibCheck": true`.
   - Include `["src/**/*.ts", "src/**/*.svelte", "vite.config.ts", "vitest.config.ts"]` — **explicitly excluding legacy `src/*.js` files** (do not enable `allowJs` or `checkJs`) so strict type checking validates all new TS/Svelte code cleanly during Phases 0–4 without failing on untouched vanilla JS.
4. **`vitest.config.ts`**:
   - Reuse `@sveltejs/vite-plugin-svelte`.
   - Set `resolve: { conditions: ["browser"] }` so `.svelte.ts` modules execute with Svelte 5's client runes runtime in Vitest.
   - Include `src/**/*.test.ts` and `src/**/*.spec.ts`.

### 4.3 Configure ESLint & Prettier (Scoped Cleanly During Coexistence)
- **`eslint.config.js`** (flat config):
  - Apply `typescript-eslint` recommended rules to `**/*.ts` and `eslint-plugin-svelte` recommended + `prettier` compatibility rules to `**/*.svelte`.
  - Add temporary ignores for `dist/`, `src-tauri/`, and legacy vanilla files (`src/*.js`) during Phases 0–4 (Phase 5 deletes legacy files and removes the temporary ignore entries).
  - Disallow explicit `any` (`@typescript-eslint/no-explicit-any: "error"`) in all new TS/Svelte code.
- **`.prettierrc` & `.prettierignore`**:
  - Register `prettier-plugin-svelte` with `.svelte` parser override.
  - Ignore `dist/`, `src-tauri/`, `pnpm-lock.yaml`, and legacy `src/*.js` / `src/styles.css` during Phases 0–4 (removed in Phase 5).

### 4.4 Relocate Entrypoint & Wire Tauri v2
1. Move `src/logo.png` → `public/logo.png`.
2. Move `src/index.html` → `index.html` at repository root and update asset paths:
   - `<link rel="stylesheet" href="/src/styles.css" />`
   - `<script type="module" src="/src/main.js"></script>`
   - Keep `<img src="/logo.png" ... />` (served from `public/logo.png`).
3. Update `src-tauri/tauri.conf.json`:
   ```json
   "build": {
     "beforeDevCommand": "pnpm dev",
     "beforeBuildCommand": "pnpm build",
     "devUrl": "http://localhost:1420",
     "frontendDist": "../dist"
   }
   ```
   Keep `"withGlobalTauri": true` for now.
4. Update `.gitignore` to ignore `node_modules/`, `dist/`, and `coverage/`.

### 4.5 Verify Vite Bundling of Legacy Vanilla App & Svelte 5 Runes Smoke Test
- Add a minimal smoke test (e.g., `src/lib/__tests__/runes-smoke.test.ts`) verifying `$state` + `$derived` + `$effect.root` + `flushSync` works inside Vitest under `resolve.conditions: ["browser"]`.
- Confirm `pnpm build` emits `dist/index.html`, `dist/logo.png`, and hashed assets under `dist/assets/` with zero inline scripts or CSP violations.
